# Qualification index

These records are the accepted evidence basis, not new API declarations.
Use [Compatibility](../Compatibility.md) to select checks and the delegated
[qualification policy](Policy.md) for acceptance criteria. Historical results
retain their actual revisions/hosts and do not certify changed code automatically.

consumers; the consolidated body is the record, not those routing pages.

their recorded source revision. A current compatibility page's navigation commit
is not the original implementation/evidence commit and must not replace it.
