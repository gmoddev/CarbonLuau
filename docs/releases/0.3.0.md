# CarbonLuau 0.3.0

First qualified experimental release.

CarbonLuau adds bounded, server-side Luau scripting to Carbon-modded Rust
servers. It ships a Carbon source package plus a platform-specific native library
containing the pinned Luau compiler and VM.

## Highlights

- Sandboxed scripts, controlled modules and transactional reloads.
- Bounded VM memory, cooperative deadlines and callback queues.
- `task.spawn`, `task.defer` and `task.delay`.
- Experimental Players, Player, Signals/Connections and Commands facade.
- Carbon permission enforcement and status/reload administration.
- Controlled-worker qualification on Windows x64 and glibc Linux x64.

## Install

Download the archive matching the server OS. Copy `CarbonLuau.cszip` to
`carbon/plugins`, place the one matching native library under
`carbon/data/CarbonLuau/native/<rid>`, and put `init.luau` under
`carbon/data/CarbonLuau/scripts`. See the complete
[installation guide](https://gmoddev.github.io/CarbonLuau/#/Installation).

```lua
local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(Player)
    Player:SendMessage(`Welcome, {Player.Name}`)
end)
```

## Compatibility and limitations

The scripting API is `CarbonLuau 0.3.0-experimental`; it is not a stable 1.0 API
or a production-readiness claim. Qualification used Carbon `2.0.259.0` and Rust
`2633` / Steam build `25230300`. Other host versions require affected checks.

Authenticated Steam/network establishment, visible client message receipt,
network-driven player lifecycle events and real same-account reconnect were not
qualified. Shockbyte full-runtime behavior is also unqualified. Cooperative
deadlines are not hard real-time guarantees, and the VM cap is not whole-process
containment. Items, `Player:GiveItem` and the Items service are not shipped.

See the [public API](https://gmoddev.github.io/CarbonLuau/#/api/README),
[API limits](https://gmoddev.github.io/CarbonLuau/#/api/Compatibility) and
[detailed Phase 5 evidence](https://gmoddev.github.io/CarbonLuau/#/Phase5-Validation).
